# جوما — مخزن کار بازنویسی فرانت

این مخزن، فضای کار مشترک محصول و فرانتِ جوماست.

## وضعیت فعلی

| مورد | وضعیت |
|---|---|
| سورس بک‌اند (PHP) | **در این مخزن نیست** — سند مادر بر پایهٔ گزارش ممیزی نوشته شده است |
| سورس فرانت فعلی | **در این مخزن نیست** — تنها ۱۷ تصویر از فرانت زندهٔ `nirbolouki.com` موجود است |
| سند مادر محصول | ✅ منتقل‌شده به `docs/00-master-spec-v0.2.md` |
| دفتر تصمیم‌ها | ✅ `docs/01-decision-register.md` |
| شکاف‌سنجی و فازبندی | ✅ `docs/02-gap-analysis-and-phases.md` |
| مرور فرانت جاری | ✅ `docs/03-frontend-audit-current.md` |
| سند طراحی (زبان بصری و توکن‌ها) | 🟡 پیش‌نویس ۰٫۱ — `docs/10-design-spec-draft-v0.1.md` |
| پیش‌نمایش زندهٔ طراحی | 🟡 `preview/` — ۶ صفحهٔ کلیدی، دو تم |
| پیاده‌سازی فرانت | ⏳ پس از تأیید سند طراحی |

> **قاعدهٔ خواندن:** سند مادر **متن مالک** است و در هر تعارض مقدم. پیوست‌ها تفسیر، فهرست و برنامه‌ریزی‌اند و جای تصمیم مالک را نمی‌گیرند.

## نقشهٔ فایل‌ها

```text
docs/
  00-master-spec-v0.2.md        ← متن سند مادر (بخش ۱ تا ۲۲) — متن مالک
  01-decision-register.md       ← PD-001..012، قراردادها، موضوع‌های باز، شکاف‌های راستی‌آزمایی
  02-gap-analysis-and-phases.md ← شکاف‌سنجی + ۸ فاز پیشنهادی + مسیر موازی امنیت
  03-frontend-audit-current.md  ← مرور ۱۳ صفحهٔ دیده‌شده در تصاویر، با نقطه‌های قوت و ضعف
  10-design-spec-draft-v0.1.md  ← سند مادر طراحی (پیش‌نویس) — زبان بصری، اجزا، الگوها، لحن

design/
  tokens.css                    ← توکن‌های دو تم (شیشه‌ای / کلاسیک) + واژگان وضعیت

preview/
  index.html                    ← پیش‌نمایش گرافیکی صفحه‌ها (دادهٔ نمایشی، بدون بک‌اند)

index.html                      ← ورودی موقت سرور پیش‌نمایش
*.jpg                           ← تصاویر فرانت زندهٔ فعلی (مرجع مقایسه)
```

## اجرای پیش‌نمایش محلی

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# سپس: http://localhost:8080/preview/
```

## سه قاعدهٔ غیرقابل‌مذاکره در این مخزن

1. **بک‌اند تصمیم می‌گیرد، فرانت نمایش می‌دهد.** تقویم جلالی، موتور موفقیت، همبستگی، مجوز و سهمیه در فرانت بازسازی نمی‌شوند.
2. **هیچ پیشنهادی با نوشته‌شدن، مصوب نمی‌شود.** موضوع باز با حدس توسعه‌دهنده پر نمی‌شود.
3. **هیچ تغییری بدون تأیید جدا روی تولید اعمال نمی‌شود.** پیش‌نمایش ≠ انتشار.

## گام بعدی

تکمیل فاز ۰ و ورود به فاز ۱ (سند طراحی): تعیین مقدار رنگ جاافتاده، تأیید نام همراه آغازین، و تثبیت واژه‌نامهٔ رابط.
