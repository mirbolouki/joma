# 7B — دموی کلاسیک، آب تصویری، تنفس و دفترچه

**وضعیت دریافت:** هیچ چیز نرسیده.

## چه چیزی از 7B لازم است

سند مادر، این بخش‌ها را از 7B مرجع گرفته است:

| قابلیت | چه چیزی باید ببینم |
|---|---|
| شفافیت، محوشدگی و جلوه‌های شیشه | دستور CSS و سطوح |
| رنگ تم کلاسیک | پالت کامل (`#0FA678`, `#2FBF8F`, `#14382E`, …) |
| ثبت تصویری آب | لیوان، سطح مایع، حرکت موج، بازخورد صوتی |
| یک دقیقه تنفس با جوما | تایمر و انیمیشن |
| ظاهر دفترچه و پیام‌های موقعیتی | کارت بینش، شواهد، چیدمان |
| سایر اجزای موجود | ناوبری، کارت‌ها، فرم‌ها |

## نکته

اگر 7B هم مثل 7A یک فایل HTML تکی است، همان را بگذار. اگر چند فایل است، همه را در همین پوشه بریز.

اگر جایی دموی زنده بالا است، آدرسش را در `reference/notes/` بنویس؛ از فایل هم گویاتر است.
