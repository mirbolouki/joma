## ۵) نقشهٔ صفحه‌های 7B

**لندینگ:** نوار بالا → hero (تیتر + زیرعنوان + دو دکمه + اعتماد + حباب جوما) + گوشی نمونه → نوار آمار → سه کارت ویژگی → «چطور کار می‌کند؟» (سه قدم ۰۱/۰۲/۰۳) → «دنیای جوما» (۸ پین) → «هم کارهایت مهم‌اند، هم حالی که داری» (با ثبت حال نمونه) → CTA → فوتر.

**اپ (دسکتاپ):** سایدبار (لوگو → دورهٔ فعال → سطح/امتیاز → «مسیر من» ۸ مورد → «راهنما» ۲ مورد → پروفایل) + تاپ‌بار (نان‌ریزه + نشان نمایشی + زنگ + آواتار) + محتوا.

**خانه:** نان‌ریزه → پیام جوما → کارت قدم بعدی + کارت حال سریع → ۴ کارت آمار → (`قدم‌های امروز` + `تخم/مراقبت`) → (`مسیر این ماه` + `بینش‌ها`).

**کارهای امروز:** سه تب (روزانه/هفتگی/ماهانه) + ستون کنار (حلقهٔ مرور روز، نکتهٔ جوما، لینک حال) + جدول ردیف‌ها: `فعالیت و هدف | مقدار انجام‌شده | وضعیت |` + بنر روز کامل + `tfoot` با دکمهٔ ذخیره. **آب به‌صورت ردیف عددی، و لیوان‌ها در کارت جدا در خانه.**

**حال من:** ویزارد ۵ قدمی (توضیح کامل در ۴.۴).

**گزارش پیشرفت:** ۳ کارت آمار → (`روند کلی وضعیت` + `تقویم ۳۰ روز گذشته` هیتمپ) → (`کارنامهٔ این هفته` با ۴ حلقه + `الگوی فعالیت` با میله‌ها و چیپ‌های دسته) → `نشان‌های جوما`.

**بخش‌های نمایشی:** «کشف و تمرین‌ها»، «کتابچه فعالیت‌ها»، «یادگیر»، «هم‌مسیر»، «برنامه من»، «راهنما و پشتیبانی»، «درباره جوما» — همه با صفحهٔ `page-ph` و پیام «در این دمو ساده‌سازی شده». **یعنی کتابخانه و برنامه و آموزش و هم‌مسیر در 7B پیاده نشده‌اند؛ مرجعشان سند مادر و فرانت زنده است.**
