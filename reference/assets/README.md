# دارایی‌های تصویری

## چه چیزی لازم است

| مورد | چرا |
|---|---|
| **جوجه و گوی** — بزرگ‌ترین کیفیت موجود | ۷ مرحله/حالت: تخم، ترک، تولد، شاد، معمولی، غمگین، خواب |
| **جغد راهنمای جوما** | همان شخصیت آبی‌ـ‌طلایی عینک‌دار |
| **لوگوی جوما** | هر نسخه‌ای که داری |
| **استیکرهای فعالیت** | سبک پینترستی — برای کارت‌های کتابخانه |
| **آیکون‌های دسته** | سلامت جسم، خواب، سلامت روان، تمرکز، یادگیری، رشد فردی، روابط، خانواده، ذهن‌آگاهی… |

## فرمت

اگر SVG برداری داری بهتر از همه. اگر PNG، با پس‌زمینهٔ شفاف و بزرگ‌ترین اندازه.
