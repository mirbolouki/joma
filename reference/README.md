# مرجع‌های طراحی — محل بارگذاری فایل‌ها

اینجا جای فایل‌های مرجع است. هر فایل که اینجا بگذاری، من از گیت می‌خوانم؛ لازم نیست در چت کپی کنی.

## چه چیزی کجا برود

| پوشه | چه چیزی |
|---|---|
| `reference/7A/` | فایل‌های دموی 7A (HTML، CSS، JS، تصاویر) |
| `reference/7B/` | فایل‌های دموی 7B |
| `reference/assets/` | تصویر جوجه و گوی، لوگو، استیکرها، آیکون‌های فعالیت |
| `reference/shots/` | اسکرین‌شات یا فیلم از صفحه‌های دموها |
| `reference/notes/` | هر توضیح، متن یا یادداشت دیگر |

## مهم

- **فایل را با نام اصلی خودش بگذار.** اگر `7a.html` است، همان بماند.
- می‌توانی فایل zip بگذاری؛ بازش می‌کنم.
- اگر فایل بزرگ است (بالای ۲۵ مگابایت)، فشرده‌اش کن یا لینک بده.
- **بعد از بارگذاری، فقط یک پیام بده:** «بارگذاری کردم». خودم می‌خوانم.
