> **منبع:** بخش اول فایل 7A دریافت‌شده از مالک (head + CSS کامل + ابتدای JS).
> **وضعیت دریافت:** ناقص — برش در وسط تابع `targ(l)`.

### ۲.۳ دستور شیشه در 7A (نقل عین قواعد)

```css
/* کارت شیشه‌ای */
background: linear-gradient(160deg, rgba(255,255,255,.42), rgba(255,255,255,.10));
border: 1.5px solid rgba(255,255,255,.85);
box-shadow: 0 12px 36px rgba(22,100,140,.22),
            inset 0 1.5px 0 rgba(255,255,255,.95),
            inset 0 -1px 0 rgba(255,255,255,.25);
backdrop-filter: blur(14px) saturate(1.6);
```

- **سه عنصر سازندهٔ «شیشه»:** گرادینت مایل سفید (`.42 → .10`)، لبهٔ سفید `1.5px`، و **هایلایت درونی** (`inset 0 1.5px 0`) روی سطح اشباع‌شده.
- **جایگزین بدون پشتیبانی:** `@supports not (backdrop-filter:blur(1px))` → `background: rgba(255,255,255,.93)`.
- شیشه روی سطوح تعاملی هم اعمال می‌شود: `.btn`, `.num`, `textarea`, `.say .bub`, `.opt`, `.p3`, `.mood-b`, `.radio-row`, `.need`, `.toast`, `.insight-pop`.
