## پیش‌نمایش ۲ چه چیزی را عیناً از دموها گرفته

| مورد | منبع |
|---|---|
| پالت کلاسیک (`#0FA678`، شش خانوادهٔ رنگی سه‌سطحی) | 7B |
| تم شیشهٔ آبی‌ـ‌فیروزه‌ای (`#1FA8B8`, `#BFE0F2`) | 7A |
| دستور شیشه: گرادینت مایل + لبهٔ نورانی + `inset` روشن + `blur(14px) saturate(1.6)` | 7A |
| ۱۰ حالت جغد و ۳۰ آیکون | 7B |
| لیوان‌های آب (`.wglasses`، ۸ لیوان، پرشدن با کلیک) | 7B |
| ویزارد حال ۵ قدمی + ۴ تصویر SVG (`heroSVG`) + ۲۵ پیام موقعیتی | 7B |
| تخم و چهار سنجهٔ مراقبت (`.psegs`) | 7B |
| حلقهٔ پیشرفت، هیت‌مپ، نشان‌ها، حباب گفتار `.joma-msg` | 7B |
| پوستهٔ سایدبار دسکتاپ + `.tabbar` موبایل | 7B |
| جوجهٔ زرد و موتور بینش ۸ قاعده‌ای | 7A (در یادداشت‌ها) |

## چه چیزی را عمداً بازنویسی کردم

| مورد | چرا |
|---|---|
| متن‌های بینش | 7A/7B متن ثابت دارند؛ سند شواهد و تعداد نمونه می‌خواهد |
| پاداش کلیک آب | سند می‌گوید پیش‌نویس پاداش نمی‌سازد |
| ریاضیات در مرورگر | سند آن را ممنوع کرده (AR-03, AR-14) |

## دو پرسش باز که پیش‌نمایش پاسخ قطعی نداده

1. **شیشه کدام باشد؟** 7A آبی‌ـ‌فیروزه‌ای است و 7B آبی‌ـ‌یاسی. دکمهٔ «شیشه» فعلاً رنگ‌های 7A را می‌گیرد و سطح/بلور 7B را.
2. **جغد کدام باشد؟** 7A حلقهٔ چشم طلایی دارد و 7B عینک طلایی. فعلاً جغد 7B استفاده شده چون آیکون‌هایش کامل‌تر است.
