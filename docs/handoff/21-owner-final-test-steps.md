## قسمت ۱ — نصب (۵ دقیقه، همان کاری که قبلاً کردی)

۱. فایل **`JOMA-TEST-PACK-v6.zip`** را دانلود کن (۱.۳ مگابایت).
۲. برو به **پنل هاست → File Manager** → داخل پوشهٔ ساب‌دامین **`test`**.
۳. دکمهٔ **Upload** → همین زیپ را بفرست.
۴. برگرد به فایل‌منیجر → روی زیپ **راست‌کلیک** → **Extract** → تأیید. (اگر پرسید جایگزین شود؟ → **بله**)
۵. در مرورگر این آدرس را باز کن: **`joma.mirbolouki.com/test/health.php`**
   → باید **سبز/سالم** نشان بدهد. اگر قرمز بود، همان تصویر یا متن را برای من بفرست.
۶. حالا این آدرس را **یک‌بار** باز کن: **`joma.mirbolouki.com/test/_SEED-DEMO.php`**
   → چند ثانیه صبر کن تا دادهٔ نمونه ساخته شود.
۷. **`_SEED-DEMO.php` را از پوشهٔ `test` پاک کن** (راست‌کلیک → Delete).
۸. `Ctrl+Shift+R` بزن (پاک‌کردن کش مرورگر) و بعد برو به **`joma.mirbolouki.com/test/`**.

**ورود نمونه:** نام کاربری **`maryam`** · رمز **`JomaTest1405!`**

## قسمت ۲ — تست (۱۵ دقیقه، ۱۱ چیز)

| # | چه کار کن | «درست» یعنی |
|---|---|---|
| ۱ | صفحهٔ اول (قبل از ورود) | بالا **یک** نوار است، نه دو تا |
| ۲ | همان صفحه، مستطیل «یک روز در جوما» | **صاف** است، کج نیست |
| ۳ | وارد شو → «کارهای امروز» → کارت لیوان‌ها | کلید **«صدای آب»** هست (خاموش باشد) |
| ۴ | چند لیوان بزن | **روان** است، صفحه نمی‌پرد |
| ۵ | روی یک لیوانِ پر **دوباره** بزن | همان لیوان خالی می‌شود، بی‌صدا |
| ۶ | کارت **تمرین تنفس** را باز کن | دایره حرکت می‌کند + جمله‌ها با هر مرحله پخش می‌شوند (اول خاموش، خودت روشن کن) |
| ۷ | «حال من» | **یکی‌یکی** می‌پرسد (پنج پرسش + یک جملهٔ اختیاری) — نه یک فرم بلند. هر گزینه شکل خودش را دارد |
| ۸ | ثبت‌نام یک حساب تازه | **پنج گام**، یکی‌یکی، **بدون گام جنسیت** |
| ۹ | «گزارش‌ها» | هر ده تب **نمودار** دارد؛ اگر جایی داده نیست، پیام روشن می‌دهد — نه صفحهٔ خراب |
| ۱۰ | «دفترچهٔ جوما» + «برنامهٔ من» | دفترچه دو بخش دارد · در برنامه «کپی ماه بعد» هست |
| ۱۱ | «خانه» → کارت **«مسیر این ماه»** | کاشی‌های رنگی + راهنمای رنگی زیرش · لمس یک روز = خلاصه‌اش زیر تقویم |

**اگر روی گوشی هم تست کنی، عالی است:** یک‌ستونی باشد، هیچ‌جا اسکرول افقی نباشد، دکمه‌ها بزرگ.
