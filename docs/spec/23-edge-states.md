# ۲۳ — دادهٔ ناکافی، خطا و حالت‌های مرزی

> **قرارداد سند مادر:** `۵٫۳` · `AR-08` · `۱۳٫۳` · `۱۹٫۲`.
> **دامنه:** این بخش **متقاطع** است. همهٔ صفحه‌ها باید با آن تطبیق داده شوند.
> **اصل:** `AR-08` — **«هیچ‌جا دادهٔ نبوده با صفر نمایش داده نمی‌شود.»**

---

## ۱) چهار وضعیت موتور — جدول مرجع

| کد | معنی | متن رابط | رنگ |
|---|---|---|---|
| `NO_DATA` | هیچ داده‌ای ثبت نشده | «برای این بازه هنوز چیزی ثبت نشده است.» | `--ink-3` |
| `NO_ELIGIBLE_CYCLES` | چرخهٔ واجد شرایط وجود ندارد | «هنوز چرخهٔ کاملی برای محاسبه وجود ندارد.» | `--ink-3` |
| `INSUFFICIENT_DATA` | داده هست ولی کم است | «برای این بازه هنوز دادهٔ کافی نیست. با چند ثبت دیگر، مقایسه معنا پیدا می‌کند.» | `--gold` |
| `AMBIGUOUS_DUPLICATE` | رخداد تکراری/مبهم | «در یک روز، بیش از یک رخداد برای یک فعالیت پیدا شد. تا رفع ابهام، این چرخه در محاسبه لحاظ نمی‌شود.» | `--coral` |

**متن دقیق از بک‌اند می‌آید.** آنچه بالا آمده، **متن پیش‌فرض** است اگر بک‌اند متن نداده باشد.

### ۱.۱ رفتار متفاوت هر کد

| کد | نمودار | جدول | کارت عدد | هشدار قابل‌بستن؟ |
|---|---|---|---|---|
| `NO_DATA` | **رسم نمی‌شود** | حذف | `.nodata` | — |
| `NO_ELIGIBLE_CYCLES` | **رسم نمی‌شود** | «چرخه‌ای نیست» | `.nodata` | — |
| `INSUFFICIENT_DATA` | **رسم نمی‌شود** | حذف | `.nodata` + دعوت به ثبت | — |
| `AMBIGUOUS_DUPLICATE` | رسم **می‌شود** (بدون چرخهٔ مبهم) | آن ردیف با چیپ `err` | عدد می‌آید | **هرگز** |

**`[تصمیم]`** در `AMBIGUOUS_DUPLICATE` عدد نمایش داده می‌شود ولی **هشدار روی صفحه می‌ماند**. `۱۳٫۳`: هشدارهای معتبر موتور «برای زیباترشدن صفحه حذف نشوند».

## ۲) جدول تصمیم: چه چیزی این وضعیت را تولید می‌کند

| جای محصول | کد ممکن | چه زمانی |
|---|---|---|
| خانه — کارت‌های عدد | `NO_DATA` | دوره تازه ساخته شده |
| خانه — نمودار مسیر | `INSUFFICIENT_DATA` | کمتر از آستانهٔ بک‌اند |
| کارهای امروز — حلقه | هیچ | نسبت «ثبت‌شده از امروز» همیشه محاسبه‌شدنی است |
| گزارش — خلاصه | هر چهار | بسته به داده |
| گزارش — تحلیل موفقیت | `NO_ELIGIBLE_CYCLES`, `AMBIGUOUS_DUPLICATE` | چرخه‌های باز بدون بستن |
| گزارش — تقویم | `NO_DATA` | دورهٔ تازه |
| گزارش — روند | `INSUFFICIENT_DATA` | سری کوتاه |
| گزارش — خلق | `NO_DATA` | هیچ حالی ثبت نشده |
| گزارش — مقایسه | `INSUFFICIENT_DATA` (یکی از دو دوره) | مقایسه انجام نمی‌شود |
| گزارش — جزئیات | `AMBIGUOUS_DUPLICATE` | رخداد تکراری |
| دفترچهٔ جوما | `INSUFFICIENT_DATA` | نمونه کم |
| جوجهٔ من | هیچ | مرحله همیشه معلوم است |

**`[تصمیم]`** این جدول **قرارداد فرانت و بک‌اند** است. هر کارتی که این کدها را نمی‌فرستد، ناقص است.

## ۳) حالت خالی — چهار صورت متفاوت

`[تصمیم]` «خالی» چهار معنی کاملاً متفاوت دارد و **باید چهار متن متفاوت داشته باشد**:

| صورت | مثال | متن | اقدام |
|---|---|---|---|
| **تازه** | کاربری که تازه آمده | «هنوز چیزی اینجا نیست. از اینجا شروع کن.» | CTA ساخت |
| **دادهٔ ناکافی** | چند ثبت، کمتر از آستانه | «چند ثبت دیگر لازم است تا اینجا معنا پیدا کند.» | CTA ثبت + شمار باقی‌مانده اگر بک‌اند بدهد |
| **فیلتر بی‌نتیجه** | فیلتر یا جست‌وجو | «با این فیلترها چیزی پیدا نشد.» | «پاک‌کردن فیلترها» |
| **خطا** | درخواست ناموفق | «این بخش الان بارگذاری نشد.» | «تلاش دوباره» |

**ممنوع مطلق:** یک متن عمومی «داده‌ای برای نمایش وجود ندارد» برای هر چهار حالت.

## ۴) سلسله‌مراتب خطا

| سطح | چه زمانی | کجا نمایش | متن |
|---|---|---|---|
| **۱. میدانی** | خطای اعتبارسنجی یک فیلد | زیر همان فیلد | «مقدار باید بین ۰ تا ۲۴ باشد.» |
| **۲. ردیفی** | خطای ثبت یک فعالیت | در همان `.trow` | «این فعالیت امروز ثبت نشد. مقدارت محفوظ است.» + «دوباره» |
| **۳. ناحیه‌ای** | خطای بارگذاری یک کارت | داخل همان کارت | «این کارت بارگذاری نشد.» + «تلاش دوباره» |
| **۴. صفحه‌ای** | خطای بارگذاری صفحه | صفحهٔ کامل | «این صفحه باز نشد.» + «تلاش دوباره» + «بازگشت به خانه» |
| **۵. اتصال** | قطع اینترنت | نوار چسبان بالای محتوا | «اتصالت قطع است.» |
| **۶. نشست** | پایان نشست | پوشش تمام‌صفحه | «نشستت تمام شده. دوباره وارد شو.» + فرم ورود |

**قاعده:** خطا **در پایین‌ترین سطحی که می‌تواند** نمایش داده می‌شود. یک خطای ردیفی نباید کل صفحه را سفید کند.

**قاعده:** خطای سطح ۶ (نشست) **داده‌های وارد‌شدهٔ ذخیره‌نشده را از بین نمی‌برد** — کاربر باید بتواند پس از ورود، همان‌جا ادامه دهد. `[تصمیم]`

---

## ۵) اتصال

| حالت | رفتار |
|---|---|
| آفلاین — صفحهٔ خواندنی | محتوای ذخیره‌شده نمایش داده می‌شود + نوار «اتصالت قطع است.» |
| آفلاین — اقدام نوشتنی | دکمه **غیرفعال** + دلیل «برای ذخیره، اتصال لازم است.» |
| بازگشت اتصال | نوار سبز کوتاه: «اتصال برگشت.» — یک بار |
| قطع وسط ارسال | مقدار **حفظ می‌شود** + «ذخیره نشد. اتصالت قطع شد.» + «دوباره» |
| کند | نشانگر پس از `2s` · پیام «کمی طول می‌کشد…» پس از `8s` |

**`[تصمیم]` هیچ داده‌ای در مرورگر ذخیره نمی‌شود.** `AR-03` — منطق و ذخیره‌سازی روی سرور است. حالت آفلاین فقط برای **نمایش محتوای قبلاً بارگذاری‌شده** است، نه برای صف‌کردن نوشتن.

**دلیل این محدودیت:** صف‌کردن نوشتن در مرورگر، یک منبع حقیقت دوم می‌سازد و `۶٫۳` («چند منبع حقیقت برای یک داده مجاز نیست») را نقض می‌کند.

## ۶) تعارض داده

| حالت | رفتار |
|---|---|
| ثبت هم‌زمان همان فعالیت در همان روز | پیام از بک‌اند: «این فعالیت امروز از قبل ثبت شده. مقدار جدید جایگزین شود؟» — فقط اگر بک‌اند اجازه دهد |
| تغییر در تب دیگر | `[تصمیم]` بدون بازخوانی خودکار. در بازگشت به تب، به‌روزرسانی + توست «داده‌ها به‌روز شد» |
| پایان نشست وسط کار | §۴ سطح ۶ |
| دو دستگاه هم‌زمان | بک‌اند تصمیم می‌گیرد؛ فرانت فقط پیام و گزینه‌های آن را نمایش می‌دهد |

**`۴٫۵`:** «قید روزانهٔ برنامه، معادل تضمین دیتابیس در برابر درخواست هم‌زمان نیست.» پس فرانت باید **انتظار** داشته باشد که این خطا برگردد و پیام مناسب داشته باشد.

## ۷) مرزها و لبه‌ها

| لبه | رفتار |
|---|---|
| آخرین روز ماه | پیام «امروز آخرین روز این دوره است» در خانه |
| اولین روز ماه جدید | دورهٔ فعال، اگر بک‌اند ساخته باشد؛ وگرنه «دورهٔ جدیدی شروع نشده» + «ساخت دوره» |
| نیمه‌شب | صفحهٔ «کارهای امروز» تاریخ را از بک‌اند می‌گیرد؛ **بدون بازخوانی خودکار ساعت مرورگر** |
| دورهٔ بایگانی و ثبت دیروز | `[نیازمند راستیآزمایی — بخش ۱۱٫۱]` تا تصمیم: فقط‌خواندنی + دلیل |
| فعالیت حذف‌شده از کتابخانه ولی موجود در برنامه | نام اسنپ‌شات نمایش داده می‌شود + چیپ «دیگر در کتابخانه نیست» `[تصمیم]` |
| ثبت با تاریخ آینده | **غیرممکن** — تاریخ‌ها از بک‌اند |
| عدد خارج از محدوده | خطای میدانی + مقدار قبلی حفظ |
| یادداشت بسیار بلند | `maxlength` از بک‌اند + شمارندهٔ فارسی |
| ورودی فارسی در فیلد عددی | پذیرفته می‌شود، خام ارسال می‌شود |
| نام کاربری با فاصله | رد می‌شود، متن خطا از بک‌اند |

## ۸) حالت‌های «نسخهٔ نمایشی» و برچسب‌گذاری

`۸.۴` و `۱۴٫۳`: تا دریافت تأیید، محصول **نسخهٔ نمایشی** است.

| مورد | رفتار |
|---|---|
| قرص «نسخهٔ نمایشی» | در نوار بالا و فوتر لندینگ |
| محتوای نمونه | **همیشه** با برچسب «نمایش نمونه» |
| پلن نمونه | با برچسب «این یک پلن نمونه است» |
| `/about` | «قابلیت نمایشی با برچسب مشخص» (`۱۳٫۲`) |
| پشتیبانی | تا اعلام کانال‌های واقعی، محتوای نمایشی با برچسب |

**`[تصمیم]`** برچسب «نسخهٔ نمایشی» **هرگز پنهان نمی‌شود** حتی اگر در چشم بیاید. `۱۴٫۳` صریح گفته تم جدید با ظاهر فعلی یکی نیست و محصول در مرحلهٔ گذار است.

## ۹) متن‌های خطای آماده — فهرست مرجع

| موقعیت | متن |
|---|---|
| ورود ناموفق | «نام کاربری یا رمز درست نیست. دقت کن یا با پشتیبانی تماس بگیر.» |
| نشست تمام | «نشستت تمام شده. دوباره وارد شو.» |
| قطع اتصال | «اتصالت قطع است.» |
| ذخیرهٔ ناموفق ثبت | «ثبت نشد. با اینترنت تلفن همراه دوباره امتحان کن.» |
| ذخیرهٔ ناموفق مقدار | «ذخیره نشد. مقدارت محفوظ است — «دوباره» را بزن.» |
| خطای سرور | «چند لحظه مشکل داشتیم. دوباره امتحان کن.» |
| خطای قطعی‌سازی آب | «ثبت نهایی انجام نشد. مقدارت محفوظ است.» |
| بارگذاری ناموفق صفحه | «این صفحه باز نشد.» |
| بارگذاری ناموفق کارت | «این کارت بارگذاری نشد.» |
| جدول خالی | «چیزی برای نمایش نیست.» + اقدام مناسب |
| دادهٔ ناکافی | «برای این بازه هنوز دادهٔ کافی نیست.» |
| چرخهٔ مبهم | «این چرخه در محاسبه لحاظ نمی‌شود تا ابهامش رفع شود.» |
| فعالیت تکراری | «این فعالیت امروز از قبل ثبت شده.» |
| برنامه قفل | متن `editReason` از بک‌اند |
| کنترل غیرفعال | متن `disabledReason` از بک‌اند |

**قاعدهٔ حاکم:** هر متن **اول مشکل، بعد راه**. هیچ متن سه‌کلمه‌ای، هیچ کد خطا، هیچ انگلیسی.

## ۱۰) حرکت در حالت‌های مرزی

| حالت | حرکت |
|---|---|
| خطا | `fadeUp .3s` ورود کارت خطا · **بدون** لرزش قرمز |
| نوار اتصال | `slide-down .25s` |
| تغییر وضعیت | انتقال نرم `0.25s` |
| `prefers-reduced-motion` | همه حذف |

**`[تصمیم]` ممنوع:** لرزش (shake)، قرمز چشمک‌زن، صدای هشدار، یا هر الگویی که تنبیه را حس کند. محصول سلامت روان است، نه فرم اداری.

## ۱۱) دسترس‌پذیری حالت‌های مرزی

| قاعده | مقدار |
|---|---|
| خطای فرم | `aria-describedby` به متن خطا · `aria-invalid="true"` |
| اعلام خطای پویا | `aria-live="polite"` روی ناحیهٔ خطا |
| خطای بحرانی | `aria-live="assertive"` |
| فوکوس پس از خطا | به اولین فیلد مشکل‌دار |
| نوارهای هشدار | `role="status"` |
| هشدار بدون‌بستن | کاربر باید بتواند بخواند؛ بدون تلهٔ فوکوس |
| کنتراست متن خطا | ≥ `۴٫۵:۱` روی زمینهٔ خودش |
| رنگ تنها نشانه نیست | هر خطا آیکون + متن دارد |

## ۱۲) پذیرش

- [ ] هر چهار کد وضعیت موتور در رابط دیده می‌شوند
- [ ] هیچ دادهٔ نبوده‌ای با صفر نمایش داده نشده

- [ ] هیچ نوشتنی در مرورگر صف نمی‌شود
- [ ] هر کنترل غیرفعال دلیل متنی از بک‌اند دارد
- [ ] هشدار چرخهٔ مبهم بسته نمی‌شود
- [ ] هیچ انیمیشن تنبیه‌گرانه‌ای وجود ندارد
- [ ] خطاها با `aria-live` اعلام می‌شوند
- [ ] رنگی که تنها نشانهٔ معنی است وجود ندارد
- [ ] متن‌ها همه فارسی و طبق واژه‌نامه‌اند
