> **منبع:** بخش ۱۹٫۱ سند مادر (فهرست واژه‌های ممنوع) · بخش ۱۳٫۵ (لحن جوما) · متن‌های واقعی 7A و 7B.
> **قاعده:** لحن مهم‌تر از زیبایی جمله است. جملهٔ زیبا که کاربر را سردرگم کند، شکست خورده است.

## ۱) لحن جوما

جوما **همراه** است، نه مربی سخت‌گیر و نه ماشین پرانرژی.

| باید | نباید |
|---|---|
| آرام و گرم | هیجان‌زده و پر سروصدا |
| واقع‌بین؛ وعدهٔ بزرگ نمی‌دهد | «زندگی‌ات را عوض کن» |
| کوتاه؛ یک ایده در هر جمله | سه بند توضیح پشت هر کار |
| همرتبه؛ «ما» و «با هم» | از بالا؛ «شما باید…» |
| پذیرای شکست؛ بازگشت آسان | سرزنش؛ «دیر شد، دیگر فایده ندارد» |
| مشخص؛ نتیجهٔ روشن | مبهم؛ «بهبود کلی وضعیت» |

### شش نمونهٔ لحن

| موقعیت | بد | خوب |
|---|---|---|
| خوش‌آمد | «به سامانهٔ جامع سلامت روان خوش آمدید» | «خوش آمدی. از یک قدم کوچک شروع می‌کنیم.» |
| کار انجام‌شده | «عملیات با موفقیت انجام شد» | «ثبت شد ✅» |
| خطای آب | «Error 500» | «ثبت نشد. با اینترنت تلفن همراه دوباره امتحان کن.» |
| بازگشت پس از غیبت | «۳ روز است ثبت نکرده‌اید. رشته‌تان پاره شد.» | «خوش برگشتی. از امروز ادامه می‌دهیم.» |
| دادهٔ ناکافی | «0%» | «برای این بازه هنوز دادهٔ کافی نیست.» |
| دعوت | «کاربر گرامی، سیستم را به دوستان معرفی کنید» | «یک نفر را کنارت بیاور. با هم راحت‌تر است.» |

## ۴) چهار الگوی متن

### ۴.۱ متن خالی (empty state)

```
[جغد]
[یک جملهٔ واقع‌بین دربارهٔ اینکه چه چیزی اینجا می‌آید]
[یک اقدام، اگر وجود دارد]
```

**نمونه:** «هنوز برنامه‌ای نساخته‌ای. جوما می‌تواند ساده‌ترین نسخهٔ برنامه را بسازد.» + دکمهٔ «ساخت برنامه»

**ممنوع:** «داده‌ای برای نمایش وجود ندارد.»

### ۴.۲ متن خطا

```
خانه‌ی مشکل (مخفف) + اینکه کجای رابط است
یک علت واقع‌بینانه و ساده، بدون حدس قطعی
یک راه مشخص برای جلو رفتن
```

**نمونه، ذخیرهٔ آب:** «ثبت انجام نشد. اگر اتصال برای لحظه‌ای قطع شده باشد همین اتفاق می‌افتد. «دوباره» را بزن تا اولین لیوان ثبت شود.»

**نمونه، ورود:** «نام کاربری یا رمز درست نیست. رمز را با دقت بیشتری وارد کن یا از «بازیابی رمز» استفاده کن.»

**ممنوع:** پیام‌های انگلیسی، کد خطا، اصطلاح فنی، «خطای نامشخص».

### ۴.۳ متن غیرفعالی

**هر کنترل غیرفعال **دلیل** خودش را می‌گوید.**

| کنترل | دلیل (از بک‌اند) |
|---|---|
| ثبت مقدار | «برای امروز ثبت قطعی شده است.» |
| دکمهٔ «بعدی» ویزارد | «اول یک گزینه را انتخاب کن.» |
| ویرایش حال دیروز | «فقط حال امروز قابل ویرایش است.» |
| دیدن گزارش | «برای این بازه هنوز دادهٔ کافی نیست.» |
| جوجهٔ من | «وقتی داده‌ها به سرور برسند، دوباره سر می‌زند.» |

**فرانت دلیل را نمی‌سازد.** اگر بک‌اند دلیل نداده باشد، کنترل غیرفعال **نمایش داده نمی‌شود**.

### ۴.۴ متن خوشامد/جشن

**حداکثر دو جمله.** بازگشت‌پذیر. بدون شمارش معکوس، بدون اضطراب.

**نمونه تولد جوجه:** «سر از تخم درآورد! از این به بعد کنار توست.»

## ۶) چه چیزی هرگز نوشته نمی‌شود

از بخش ۱۹٫۱ سند مادر:

| خط قرمز | چرا |
|---|---|
| «شما» رسمی و تشریفاتی | فاصله می‌سازد |
| اصطلاح علمی بدون توضیح («طرحوارهٔ رهاشدگی») | کاربر متخصص نیست |
| وعدهٔ درمان یا نتیجه | مسئولیت حقوقی و اخلاقی |
| عدد یا درصد بدون منبع | اعتماد را از بین می‌برد |
| «۰٪» برای دادهٔ نبوده | دروغ است |
| شمارش معکوس تهدیدآمیز | فشار روانی |
| تحقیر یا مقایسه با دیگران | `PD-008` |
| مقایسهٔ کاربر با میانگین دیگران بدون خواست خودش | `10.10` |
| زامبی‌وار «کاربر عزیز» | بی‌هویت |
| کلمهٔ فنی: `balance`, `token`, `session`, `API` | کاربر نمی‌فهمد |
| ایموجی به‌جای واژهٔ معنادار | ناخوانا در برخی وسایل |
| انگلیسی درون متن فارسی | دوگانگی بصری |
| **«آبت کامل شد» و هر جمله با «آبت»** | 🔴 تصمیم مالک (۱۴۰۵): در فارسی بار جنسی دارد. واژهٔ درست: «نوشیدنت کامل شد» · «آب امروزت» · «آب را اضافه کن» |
| «کد پیامک شد» / «ارسال دوباره» برای کد ثبت‌نام و بازیابی | پیامک سیستم وصل نیست؛ کد دستی از پشتیبانی می‌آید (`۲۲` §۳.۱) |
| «راهنمای تمرین» در کارت پیشنهاد تنفس | تصمیم مالک: حذف شد — تمرین خودش کامل است، با صدای راهنما |
