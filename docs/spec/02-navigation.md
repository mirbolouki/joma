## ۲.۶ پهنای محتوا — قاعدهٔ سراسری

> ### 🔴 تصمیم مالک
> «کاری کن فعالیت‌ها در دسکتاپ هم عریض نباشند؛ زیبایی بصری ندارد.»

```css
.content { max-width: 1180px; margin-inline: auto; padding-inline: 22px }
```

| عرض نمایشگر | عرض محتوا | شبکه |
|---|---|---|
| `< 1200px` | تمام پهنا با حاشیهٔ `22px` | تا ۲ ستون |
| `≥ 1200px` | **حداکثر `1180px`، وسط‌چین** | ۳ ستون |
| `≥ 1700px` | **همان `1180px` — بیشتر نمی‌شود** | همان ۳ ستون |

**سه قاعدهٔ سخت:**

| # | قاعده | چرا |
|---|---|---|
| ۱ | سقف محتوا `1180px` است و با نمایشگر بزرگ‌تر **نمی‌شود** | متن در سطر بلند، ناخوانا می‌شود |
| ۲ | شبکهٔ کارت‌ها از **۳ ستون** بیشتر نمی‌شود و هر کارت از `440px` پهن‌تر نمی‌شود | کارت پهن، خالی به نظر می‌رسد |
| ۳ | فضای خالی با **کشیدن کارت** پر نمی‌شود | `[تصمیم]` |

**جدول‌ها:** ستون‌ها نسبت ثابت می‌گیرند، نه `1fr` مساوی. جزئیات در `12-today.md` §۱۰ و `17-library.md` §۱۰.

## ۶) عمق ناوبری

**حداکثر دو پرش از خانه تا هر کار روزمره.**

| کار | مسیر |
|---|---|
| ثبت مقدار امروز | خانه ← کارهای امروز ← ثبت |
| ثبت حال | خانه ← حال من ← ۵ قدم |
| دیدن یک تمرین و ثبتش | آموزش ← تمرین ← «ثبت در امروز» |
| افزودن فعالیت | کتابخانه ← کارت فعالیت ← «افزودن به برنامه» |
| دیدن الگو | گزارش‌ها ← تب |

**قاعده:** هر صفحه یک **بازگشت واضح** به والد دارد.

## ۷) حالت‌های ناوبری

| حالت | رفتار |
|---|---|
| کاربر تازه‌وارد | بدون دوره و برنامه. صفحه‌های «امروز»، «حال» و «گزارش» با **حالت راهنما** نمایش داده می‌شوند، نه صفحهٔ خالی. |
| بدون دوره فعال | سایدبار به‌جای نام دوره: «دوره‌ای فعال نیست» + دکمهٔ «ساخت دوره». |
| بدون بینش | نشانگر «دفترچهٔ جوما» نمایش داده نمی‌شود؛ خود صفحه حالت خالی دارد. |
| پیش از تولد جوجه | کارت سطح، ایموجی تخم را نشان می‌دهد. |
| هم‌مسیر بدون ارتباط | مقصد فعال است؛ صفحه با حالت خالی و CTA «دعوت همراه» می‌آید. |
| نقش همراه | مقصدهای «جوجهٔ من» و «حال من» **حذف نمی‌شوند**، ولی محتوای شخصی مراجع نمایش داده نمی‌شود؛ فقط بخش مجاز. |

> **`[نیازمند راستی‌آزمایی]`** رفتار ناوبری برای نقش «همراه» و «مدیر» باید با بک‌اند تطبیق شود. سند مادر می‌گوید نقش از بک‌اند می‌آید (`۷٫۱`) ولی ناوبری نقش‌محور را تعریف نکرده.
