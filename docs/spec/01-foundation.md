# ۰۱ — پایهٔ بصری (توکن‌ها)

> همهٔ مقادیر این بخش **از فایل‌های 7A و 7B استخراج شده‌اند**. جایی که تصمیم طراحی است، `[تصمیم]` خورده.
> **قاعده:** کامپوننت‌ها فقط از این توکن‌ها مصرف می‌کنند. هیچ رنگ، فاصله و شعاعی داخل کامپوننت hardcode نمی‌شود.

### ۲.۴.۱ جغد — **همان جغد مرجع، متحرک. نه استیکر، نه ایموجی** 🔴

> ### تصمیم مالک (۲۶ شهریور)
> «من آن **استیکر جغد** را نمی‌خواهم که در پیش‌نویس‌ها دیدم؛ من همان **جغد انیمیشنی در فایل‌های نمونه** را می‌خواهم.»

**`[تصمیم]` جغد، یک کتابخانهٔ آمادهٔ مشخص است — نه چیزی که دوباره کشیده شود.**

| | |
|---|---|
| **منبع قطعی** | نمادهای SVG در `reference/7B/7B.html` — **همان فایل مرجع، همان مسیرها** |
| **نمادها** | `#owl-core` (بدنه) · `#owl` · `#owl-hi` · `#owl-cheer` · `#owl-think` · `#owl-read` · `#owl-moon` · `#owl-lotus` · `#owl-water` |
| **چگونه استفاده می‌شود** | `<svg><use href="#owl-hi"/></svg>` — همان روشی که مرجع استفاده می‌کند |
| **رنگ** | از توکن‌های `--owl-*` (§۲٫۴) — پس با تعویض تم، جغد هم عوض می‌شود |
| **اندازه** | `28` · `34` · `40` · `46` · `52` · `56` · `62` · `64` · `70` · `90` پیکسل (مقیاس 7A/7B) |

#### ممنوعیت‌های سخت — این‌ها **استیکر** می‌سازند

| ❌ ممنوع | چرا |
|---|---|
| **ایموجی `🦉`** | ایموجی، جغدِ جوما نیست — شکل و رنگش را سیستم تعیین می‌کند، نه ما |
| **کشیدن جغد تازه** | جغد، هویت است. جغد بازکشیده‌شده، جغد دیگری است |
| **جغد تک‌رنگ/خطی/خاکستری** | جغد مرجع رنگی است (آبی + کرم + طلایی) |
| **جغد ثابت و بی‌حرکت در صفحه** | حرکت، بخشی از هویت است — نه افزودنی |
| **جغد در گفت‌وگوی هم‌مسیر** | `20-hammasir.md` §۲۷۱ — گفت‌وگوی دو انسان است |

#### حرکت — الزامی، نه تزئینی

| حرکت | مقدار | کجا |
|---|---|---|
| **`floaty`** (شناوری آرام) | `translateY(-7px)` · `3.2s` · بی‌نهایت | جغدهای بزرگ: خوش‌آمد، آشیانه، آموزش، لندینگ |
| **`wiggle`** | `±6deg` · `.5s` | کلیک روی جغد — **بدون هیچ پاداشی** (`CAR-01`) |
| **`cheer`** | جرقه‌های طلایی/رزی دور سر | تکمیل کارها، پایان مراحل |
| **`pop`** | `scale(1.3)` در ۴۰٪ | تغییر چیپ فعالیت |
| **پلک** | با نمادهای چشم‌بسته (`#owl-moon` · `#owl-lotus`) — **نه با انیمیشن کردن مردمک** | حالت خواب/آرامش |
| **`prefers-reduced-motion`** | همه خاموش — جغد ثابت می‌ماند، ولی **همان جغد** | همه‌جا |

**`[تصمیم]` و یک قاعدهٔ جزئی:** جغد رنگش را از `--owl-*` می‌گیرد و **هرگز از تومان‌های برند (`--brand`)** — وگرنه در تم شیشه، جغد سبز می‌شود و هویت می‌شکند.

**`[تصمیم]` برای ایجنت پیاده‌ساز:** نمادها **کپی** می‌شوند (از `reference/7B/7B.html` خطوط ۵۰۹ به بعد) — **از نو طراحی نمی‌شوند** و هیچ ابزار طراحی‌ای وسط نمی‌آید.

### ۳.۳ دستور شیشه — مهم‌ترین بخش

شیشهٔ واقعی **سه عنصر هم‌زمان** است. حذف هرکدام، نتیجه را به «سفید محو» تبدیل می‌کند:

```css
[data-theme="glass"] .card{
  /* ۱. گرادینت مایل — از بالا-چپ روشن‌تر به پایین-راست شفاف‌تر */
  background: linear-gradient(160deg, rgba(255,255,255,.42), rgba(255,255,255,.10));
  /* ۲. لبهٔ نورانی */
  border: 1.5px solid rgba(255,255,255,.85);
  /* ۳. هایلایت درونی بالا + سایهٔ پایین + سایهٔ محیطی */
  box-shadow: 0 12px 36px rgba(22,100,140,.22),
              inset 0 1.5px 0 rgba(255,255,255,.95),
              inset 0 -1px 0 rgba(255,255,255,.25);
  backdrop-filter: blur(14px) saturate(1.6);
  -webkit-backdrop-filter: blur(14px) saturate(1.6);
}
```

**`inset 0 1.5px 0 rgba(255,255,255,.95)`** همان خط نور روی لبهٔ بالای کارت است. بدون آن، کارت مرده به نظر می‌رسد.

**`saturate(1.6)`** رنگ پشت شیشه را زنده‌تر نشان می‌دهد. بدون آن، شیشه خاکستری می‌شود.

### ۳.۴ سطوحی که شیشه می‌گیرند

سایدبار · نوار بالا · کارت · دکمه · ورودی عددی · متن‌نویس · حباب گفتار · گزینهٔ حال · کارت بینش · توست · سطر جدول.

**سطح مات لازم:** پنجرهٔ تأیید عملیات و ورودی‌های اصلی باید **تقریباً مات** باشند تا خوانا بمانند (`14.2`). شفافیت بیشتر، خوانایی را قربانی می‌کند.

### ۳.۵ جایگزین‌ها

```css
/* بدون پشتیبانی بلور */
@supports not (backdrop-filter: blur(1px)){
  [data-theme="glass"] .card,
  [data-theme="glass"] .side { background: rgba(255,255,255,.93); }
}

/* کاربر حساسیت به شفافیت را خاموش کرده */
@media (prefers-reduced-transparency: reduce){
  [data-theme="glass"] .card{ backdrop-filter:none; background:#F6FAFD; }
}
```

هر دو حالت باید پیاده شوند. در هیچ‌کدام، محتوا یا سلسله‌مراتب تغییر نمی‌کند.

## ۶) دسترس‌پذیری — الزامی

| معیار | مقدار |
|---|---|
| کنتراست متن معمولی | ≥ `4.5:1` |
| کنتراست متن بزرگ (≥۱۸px یا ≥۱۴px بولد) | ≥ `3:1` |
| کنتراست عنصر غیرمتنی مهم (مرز ورودی، آیکون وضعیت) | ≥ `3:1` |
| سطح سنجش کنتراست در تم شیشه | **سطح ترکیب‌شدهٔ واقعی**، نه سفید |
| رنگ به‌تنهایی نشانهٔ وضعیت | **ممنوع** — همیشه متن همراه |
| `aria-label` فارسی برای هر ایموجی معنادار | الزامی |
| ترتیب فوکوس | منطقی و مطابق ترتیب بصری |
| بستن پوشش‌ها | با `Esc` و دکمهٔ واضح |

**نکتهٔ شیشه:** `--ink-3` یعنی `#6E869C` روی سطح `rgba(255,255,255,.34)` ممکن است به ۴٫۵ نرسد. `[نیازمند راستی‌آزمایی]` — باید با ابزار سنجیده شود و در صورت نیاز تیره‌تر شود.
