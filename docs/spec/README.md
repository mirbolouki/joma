## قاعدهٔ طلایی این سند

هرجا این سند عددی می‌دهد، آن عدد **از فایل 7A یا 7B استخراج شده** و در ستون «منبع» ارجاع دارد.
هرجا **تصمیم طراحی** است، با برچسب `[تصمیم]` مشخص شده.
هرجا **چیزی نمی‌دانیم**، با برچسب `[نیازمند راستی‌آزمایی]` آمده و حدس زده نشده.
